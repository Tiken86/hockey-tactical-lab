# Hockey Tactical Lab

Seminario Práctico: Del Modelo a la Tarea

Aplicación web interactiva para el diseño y análisis táctico en hockey. Esta herramienta permite crear, analizar y diseñar tareas de entrenamiento basadas en el modelo de juego.

## Características

- ✅ **Análisis Táctico**: Análisis detallado de problemas del juego
- ✅ **Diseño de Tareas**: Crea 4 tipos de tareas (Dirigida, Estructurada, Especial, Competitiva)
- ✅ **Persistencia Automática**: Guardado automático en el navegador
- ✅ **Exportación**: Exporta tus proyectos en formato JSON
- ✅ **Informes PDF**: Genera informes técnicos imprimibles
- ✅ **Responsive**: Funciona en dispositivos móviles y tablets

## Uso

1. Abre `index.html` en tu navegador o visita la URL de GitHub Pages
2. Ingresa el nombre de tu grupo
3. Selecciona el momento del juego a trabajar
4. Completa el análisis táctico
5. Diseña las tareas de entrenamiento
6. Genera el informe final

## Tecnologías

- React (via CDN)
- Tailwind CSS
- Babel Standalone
- HTML5

## GitHub Pages

Este proyecto está configurado para funcionar en GitHub Pages. Una vez configurado, la aplicación estará disponible directamente en la URL raíz de tu sitio.

**URL de ejemplo**: `https://TU_USUARIO.github.io/hockey-tactical-lab/`

No necesitas agregar `/index.html` al final, ya que GitHub Pages servirá automáticamente el archivo `index.html` como página principal.
